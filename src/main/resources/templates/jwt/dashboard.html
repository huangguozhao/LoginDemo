📚 JWT认证说明

  • 认证方式：基于JSON Web Token的无状态认证
  • 安全性：使用HMAC-SHA256算法签名，包含过期时间
  • 扩展性：优秀的水平扩展性，适合分布式系统
  • 优点：无状态设计，跨域友好，客户端可缓存
  • 缺点：无法主动失效，Token较大，签名算法重要
