🔗 OAuth2 / OIDC 技术详解

  • 授权码流程: 最安全的OAuth2流程，通过前端重定向实现
  • Access Token: 用于访问受保护资源的短期令牌
  • ID Token: OIDC特有的身份令牌，包含用户信息
  • Refresh Token: 用于获取新的Access Token，无需重新授权
  • Scopes: 定义应用可以访问的用户信息范围
  • 第三方信任: 用户信任OAuth2提供商管理身份信息
